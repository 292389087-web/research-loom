## 真实 CUDA 工程回归

使用作者本机登记的完整训练适配器与私有数据，自动填入一组固定参数、单 seed，连续训练 10 个仿真日，从头初始化。目的为验证新版诊断和交付契约，不搜索“更优参数”。

- 训练状态 `completed`，产物状态 `accepted`。
- PyTorch 峰值已分配显存约 0.39935 GiB；这是框架统计，不是整卡显存占用。
- 10 天逐日子项均值加和与 `mean_step_reward` 的最大差异 `3.637978807091713e-12`。
- 独立数据分析页按固定筛选条件生成 18 行逐日分析，逐行与训练原始 JSON 核对一致。
- 单 seed，不能估计种子间标准差；阶段为 `training`，不是独立测试集效果。

隔离回归还包含 501 组奖励状态，比较新旧函数：标量 reward 全部严格相等，子项加和最大浮点误差 `2.1316282072803006e-14`，确认补齐日志不改变奖励计算。这属于日志正确性证据，不代表策略效果改善。

真实训练回执、逐日数据、分析快照与训练产物清单保留在本机 `data/`；公开部分见 `real-run/`。

## 使用与剩余边界

重启现有 API 服务及独立实验调度进程后才使用新逻辑。资源检查需要适配器诚实声明动态依赖及模型文件；训练进程并非沙箱。产物限额不是磁盘配额。当前为单用户本机 SQLite、串行 GPU 调度；没有因为这些改进宣称分布式系统已完成。
