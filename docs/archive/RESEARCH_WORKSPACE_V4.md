# 从实验设计到科研数据分析

03 回答“下一轮怎么做”，负责固定配置、运行、记录和人工审核建议。04 回答“已有数据支持什么结论”，负责独立选择数据、跨轮汇总、图表、导出和初稿数字核查。04 不启动训练，也不要求先在 03 选择某个计划。

## 03：参数分组与控制变量

训练适配器增加 `parameter_groups`、`parameter_labels` 和 `metric_metadata`。参数类别为 reward、hyperparameter 或 protocol；没有分类的字段显示“未分类”，不能由模型猜测类别。已登记训练工程的清单已补充类别、中文标签、指标单位和角色；本次未改写训练算法。

| 本轮目的 | 必需输入 | 可变配置 | 保持不变 |
|---|---|---|---|
| 建立基线 | 完整配置和评价协议 | 全部配置 | 启动后全部冻结 |
| 调整奖励函数 | 已结束且有记录的基准轮 | reward 组 | 超参数、训练天数、seed、评价协议 |
| 调整模型超参数 | 已结束且有记录的基准轮 | hyperparameter 组 | 奖励系数、训练天数、seed、评价协议 |
| 重复验证 | 已结束且有记录的基准轮 | 不改变参数 | 完整配置和相同 seed；从头执行，非 checkpoint 续训 |

界面使用分组表单，JSON 仅作完整配置预览。变更展示基准值与新值；同时改变多个字段会提醒归因限制。后端对手工派生、模型建议和人工修改执行组别校验，不能绕过网页同时改奖励与 PPO 超参数。

派生时检查代码哈希、数据快照、包版本、参数分类和评价协议。任一关键口径变化必须建立新基线。旧记录不回写；没有冻结类别的旧实验可查看和分析，但不能直接派生调参。手工从基准创建或通过建议审核创建都只产生 draft，需要单独启动。

“下一轮允许调整的类别”单独选择，不等于本轮曾调整的类别。允许字段随建议请求冻结，越组建议和人工修改会被拒绝。

## 03：多指标评价

- 重点观察指标支持多选；所有实际指标仍保存。
- 默认排序指标可以为空，不代表“允许调几个参数”，也不是训练 reward。
- 约束支持 le 上限和 ge 下限；任一 seed 违反即不满足约束。缺失所选观察/约束指标时执行失败，不补零。
- 每个指标汇总 seed 均值和样本标准差；单 seed 标准差显示未知。
- 不自动将不同量纲指标加权成“最优”结论。

已登记训练工程的 `evaluation_loss` 显示为“历史综合评分（非 PPO loss）”，并注明其为历史兼容字段。默认不选它；不是通用科学评价标准。改变 reward 权重后，总 reward 不能横向证明策略更好；04 将奖励定义纳入对应指标的可比键。

## 04：独立数据来源

### 平台实验

在 04 内按项目勾选多个轮次，创建不可变快照。每个 Study/Trial 是一个实验组，每个成功 Attempt 是一个 seed 样本。未完成、失败、取消等记录单独保留，不计作零值。来源可回到 attempt ID，原实验后续变化不影响旧快照。

平台快照记录代码、数据、环境、协议、协议类参数及阶段。默认只有上述口径、单位和 seed 集合一致才计算差值或排名；不一致仍可分别查看统计。不同实现代码的算法对比不能默认认定可比，可通过研究者确认协议的 CSV 分析。规则仅是必要条件，不证明科学可比或数据真实性。

旧适配器未声明单位时显示“未声明”，不自动推断/换算，也不计算相应差值、排名和核查。`validation_only` 是适配器声明，不代表平台证明其独立运行了验证集，更不是测试集结论。

### CSV 导入

下载页面模板，使用长表，列顺序固定：

```csv
group,seed,metric,value,unit,protocol,phase
baseline,11,grid_energy,100,kWh,fixed-eval-v1,evaluation
candidate,11,grid_energy,95,kWh,fixed-eval-v1,evaluation
```

上例仅为格式说明。group 是算法/消融配置/轮次，seed 为整数，value 为有限数字，unit 显式注明单位，protocol 为用户确认的评价协议，phase 只能是 training 或 evaluation。

导入时填写来源说明并预览 CSV。最多 1000 行、55000 字符，并受 HTTP 64 KiB 请求体限制；中文较多可能先达到字节上限。拒绝缺字段、重复 group/seed/metric、非有限值和同名指标单位冲突；同组混合协议在分析时拒绝聚合。相同 protocol 字符串不等于平台证明数据真实可比。

### 内置演示

“打开演示数据”生成三组、各三个 seed 的固定合成数据，展示能耗与温度的取舍。页面、报告和图表标记合成演示，不计入真实训练或模型质量成果。无需显卡和 API Key 即可直接分析。

## 分析、图表与自然语言

选择数据集 → 选择多个指标与可选基准 → 生成对照表 → 查看均值、标准差、样本数、约束与差值 → 导出 CSV、来源 JSON 或 SVG。排名另外要求明确排序指标与方向。

图表是原始量纲的均值条形图，标准差在表格中报告。当前没有误差条、置信区间、显著性检验、Pareto 认定或因果归因。差异解释由确定性模板生成，不自动宣称算法优越。

自然语言链路为“问题与字段 → 受约束 DataPlan → 确定性计算 → 持久报告”，支持 compare、summary、failures、rank。无评价标准的“最好/最优”问题要求补充；超出能力可返回 clarification。模型不能生成并执行任意 SQL/Python。

规划复用持久队列、租约、模型调用账本、Prompt 版本、路由和重放。平台实验需要任务及关联实验全部祖先许可；CSV 需要数据集许可和本次任务许可。只发送问题、组标识和字段元数据做规划，计算结果由后端产生。直接分析按钮不调用模型。

## 初稿数字核查

- 降幅：第一项是基准、第二项是对照，同指标/单位/协议/seed，公式 `(baseline-current)/baseline*100`，基准必须为正。
- 求和：选择同单位子项，按各自 seed 均值求和；不允许重复选择同一组同一指标。

用 Decimal 计算并保存公式、输入、报告值、计算值、差值、容差、快照和逐项来源。可绑定 02 当前保存的初稿，要求语句存在于该版本中；也可核对独立语句。02 原有普通/加权求和保留。当前不自动提取整篇论文的数字，也不证明原始数据真实。

## 接口、存储与兼容

新表 `research_datasets` 保存不可变快照，`research_reports` 保存分析和核查。主要接口：

| 接口 | 用途 |
|---|---|
| `POST /api/data/import` | CSV 与来源说明 |
| `POST /api/data/from-studies` | 多轮实验快照 |
| `POST /api/data/demo` | 合成演示 |
| `GET /api/data/datasets` | 独立数据列表 |
| `POST /api/data/datasets/{id}/analyze` | 确定性分析 |
| `POST /api/data/questions` | 模型规划任务 |
| `POST /api/data/audits` | 数据核查 |
| `GET /api/data/reports/{id}/export` | CSV/JSON 导出 |
| `GET /api/data/reports/{id}/chart` | SVG |

旧 `/api/analyses` 和单 Study 分析接口保留兼容，04 已切换到新接口。继承严格 schema、绑定参数 SQL、入口限长、外发许可和模型账本；CSV 防公式注入，SVG 文本转义。历史实验、原始回答和旧指标不因本次升级重写。
