# 研究工作区操作说明

03/04 的完整流程见 [批量实验管理](BATCH_EXPERIMENTS.md)，2026-09-22 新增功能见 [工程补强说明](ENGINEERING_HARDENING_20260922.md)。本文保留启动、路由和适配器接入说明。

本版本把“读论文与找方向 → 配置真实实验 → 查看实验数据 → 引用与初稿核查”连接起来。原有研究页在 `/`，新增功能在 `/workspace`。所有新代码位于 `research-loom`，原项目不变。

## 启动

在三个终端进入项目根目录，分别执行：

```powershell
python start.py --api-only --workers 2
python -m loom.worker_main --supervise
python -m loom.lab_worker
```

三个进程使用相同 `LOOM_DATA_DIR`，默认 `research-loom/data`。API 只监听 `127.0.0.1:8010`；不需要公网地址。两个 API 进程不代表两个 GPU 推理副本。实验调度器使用 OS 文件锁保证同一数据目录只有一个实例；`/api/lab/status` 可检查最近心跳。

若只读论文，可以继续 `python start.py`。需要执行人工确认后的实验计划时，另行启动 `loom.lab_worker`。已启动计划与结果不会因关闭页面而丢失；不要把 SQLite 放在网络共享盘来模拟多机数据库。

## 混合路由

优先级：资料许可 → 用户选择 → GPU 状态 → 任务复杂度。

| 条件 | 行为 |
|---|---|
| 默认配置 | 本地 Qwen3-VL，API 关闭 |
| 简单任务、GPU 可用 | 自动模式优先本地 |
| 研究方案、方案复核、分析计划或较大上下文 | 在配置和许可齐全时走 API |
| GPU 被实验占用 | 获许可任务可以走 API；其他任务持久等待 |
| 强制 API 但资料未许可 | 拒绝外发，不以用户选择覆盖资料许可 |
| 图片 | 额外需要图片许可与 API 图片能力声明 |

文献外发必须同时具备“文献库中的许可”和“本次任务许可”；历史对话也检查许可。实验分析检查冻结计划的许可与本次任务许可。**许可默认关闭。** 初稿和用户问题属于本次任务资料，勾选外发意味着允许发送这些内容。

DeepSeek V4.1 Flash 已有预设配置：在 `config/deepseek.local.toml` 中填写 `api_key`，重启 API 与模型 worker 即可。该本地文件已加入 `.gitignore`，可分享的空白模板为 `config/deepseek.example.toml`。模型 ID 为 `deepseek-flash`。详见 [DeepSeek 配置说明](../config/README.md)。

服务进程也读取以下环境变量，优先级高于文件。密钥不要写进源码、文档、对话或浏览器：

```text
LOOM_REMOTE_URL     OpenAI-compatible 服务的 base URL，不含 /chat/completions
LOOM_REMOTE_MODEL   服务商实际模型 ID
LOOM_REMOTE_KEY     从本机环境提供的密钥
LOOM_REMOTE_VISION  默认 0，仅确认所选模型支持图片后设为 1
```

实现为通用 Chat Completions JSON 契约；不同服务商的推理参数、上下文和计费规则仍需真实接入测试。连接不自动跟随重定向，不把失败响应或密钥记录进账本。每个任务最多 4 次 API 调用；DeepSeek 预设开启 high 强度思考，每次最多 32768 个输出 token，累计上限 131072，包含思考和最终回答。未加载预设文件时沿用原 7000 token 上限。总模型调用仍受 8 次限制。输出 token 预留不是货币预算，缺失用量标为未知，未配置价格不计算费用。

每个阶段的路由、模型和端点指纹持久化。重放已记录回答不再调用模型；未知调用可能重复，不能承诺 exactly-once。已选择 API 的阶段不会悄悄换模型重跑；后续阶段重新判断资源。超时后的服务端执行情况可能未知。

本地推理和训练使用同一个 GPU 文件锁。本地每次调用后卸载权重、同步 CUDA、清理缓存，然后交还锁；因此会增加下一次调用的加载延迟。训练包装进程持锁到退出。锁只能约束本平台的协作进程，不会阻止外部软件占用显卡，也不能保证任意训练都装得下。

## 文献库与引用

在原研究页导入 PDF，然后在文献库填写作者、年份、期刊／会议、DOI、发表状态。等级评分需要同时填写体系、级别、目录年份、来源；平台不会编造 CCF 或中科院等级。`work_id` 可合并同一研究的不同版本。保存使用乐观版本检查，旧页面覆盖新修改返回 409。

在初稿页保存正文版本，用空行分段，再选择文献生成引用候选。首版每次覆盖前 4 段，每段前 800 字，检索后展示给模型最多 10 个证据片段；长文按节处理。结果保留具体覆盖范围、初稿哈希、段落哈希、插入位置、证据页和文献修订号。

得分默认由检索候选排名占 70%、年份占 15%、用户等级偏好占 15% 组成，可修改权重。年份在 15 年窗口内线性衰减；缺失年份／等级使用 0.5 的中性项并明确标记。相关度是本次候选检索排名的归一化代理，不是经过标注评测的语义概率。匹配不到原文摘录，或关系为矛盾／不确定的候选不进入可引用排名。模型判定的支持关系仍需要人核查。

引用建议不直接改写初稿，也尚未提供 Word／LaTeX 插件。编辑正文后必须保存新版本，旧位置不能自动套用。

## 真实训练接入

平台不会凭 PDF 编造训练程序或实验结果。训练源码、数据和大体积产物可以只保留在个人电脑，但当前机器执行前必须存在本地训练目录、数据与已登记可信适配器；对外发布时用脱敏 manifest 和哈希说明对应版本。

本地清单格式如下。路径及指标应替换为真实工程中的值；以下只是接口示例，不代表这组示例参数已完成真实训练：

```json
{
  "id": "my-research",
  "name": "我的训练工程",
  "root": "D:/my-training",
  "entrypoint": "loom_adapter.py",
  "source_files": ["loom_adapter.py", "model.py", "environment.py"],
  "dataset_files": ["data/validation.csv"],
  "parameters": {"H": [50, 100, 200, 500], "reward_weight": [0.01, 0.02]},
  "metrics": ["validation_energy", "violation_rate"],
  "fixture": false
}
```

```powershell
python -m loom.register_trainer .\adapter\manifest.json
```

登记只通过本地 CLI，不接受浏览器上传可执行脚本。适配器必须在**同一包装进程**内完成训练，不能另起 GPU 子进程、后台守护进程或 DDP；普通 subprocess 并不是沙箱。代码清单应覆盖实际实现，未列出的外部依赖不享有源码快照保证。当前使用同一 Python 环境，清单记录主要包版本但不会自动创建锁定环境。

入口收到 `--config <配置文件> --output <运行目录>`，在运行目录写最终 `metrics.json`，内容是有限数值的指标映射。目标和约束指标必须存在。可选 SDK：

```python
from loom.training import TrainingContext

ctx = TrainingContext.from_cli()
config = ctx.config
# 在真实训练代码中使用 config["seed"] 初始化 Python / NumPy / Torch / 环境随机状态。
# params = config["parameters"]；data_root = config["data_root"]
# 按需 ctx.report(step, {"validation_energy": value}, axis="environment_step")
# ctx.finish({"validation_energy": measured_energy, "violation_rate": measured_rate})
```

SDK 通过临时文件、flush/fsync、rename 发布指标；进度写入限制为 10 MB 的 JSONL。坐标区分环境步、优化器步、episode、模拟秒。文件接口提供配置、源版本清单、日志、进度和结果哈希；04 已支持显式登记逐日产物的曲线，不从任意训练日志猜测字段。自行实现的适配器也应原子发布指标。

创建批次冻结代码/数据哈希、完整候选矩阵、观察指标、可选排序指标、上下限约束、seed 和预算。可以选择单参数扫描、多参数笛卡尔积或手工指定完整配置行。网页预览全部组合和训练次数，确认后创建 draft，再单独启动。执行阶段不调用模型。最多 8 个活动计划，单 GPU 串行。

总期限和每个 seed 的超时均为墙钟时间。可请求当前 seed 完成后暂停，并在原期限内恢复剩余任务。失败可设为完成该组后暂停或继续；未知结果保留，不隐式重跑。详细边界见 [批量实验说明](BATCH_EXPERIMENTS.md)。

### 历史自动搜索模式（当前入口禁用）

0.3 历史版本曾支持 TPE、随机搜索和受限 API 候选控制器。相关 schema、读取逻辑和历史记录保留兼容；当前批次走矩阵预览/确认接口，可运行多组配置和共同种子。旧自动搜索计划不能从当前入口重新启动。不要把旧单轮接口的限制套到当前批次上，也不要将历史自动调参描述成当前能力。

同一参数组合对应一个 Trial，每个 seed 对应一条独立重复执行记录。首版每个重复只有一次真正执行；包装器最多重启启动过程 3 次，CAS 保证只允许一次进入训练。进程死亡或结果未知时标失败，**不会自动重新训练或把它计作新的 seed**。精确 checkpoint/resume 尚未接入；新计划默认重新训练，不继承权重。

失败记录保留，不参加成功排名。只有所有 seed 成功才汇总均值、样本标准差和约束满足情况。一个 seed 没有可报告的样本标准差。目标、数据划分、验证集与测试集隔离需要适配器真实遵守，平台无法从任意 Python 代码自动证明无泄漏。修改奖励权重时，应固定外层物理评价目标，不能最大化已经变换口径的总奖励。

## 实验 Data Agent 与初稿核查

04 当前独立选择多个 Study 或导入 CSV，形成不可变 research_datasets；自然语言映射到受限 DataPlan，后端计算并保存 research_reports。支持多指标对照、明确标准的排名、汇总与失败记录、SVG/CSV/JSON 导出。不依赖 03 当前选择，直接计算不调用模型。旧单 Study AnalysisSpec 接口只保留兼容。

均值和差值是描述性统计；协议、单位、seed 或奖励定义不符时禁止相应差值与排名。支持最终指标条形图、参数筛选和逐日曲线，标准差在表格展示。时间缺口或种子缺失不能自动补零。没有自动显著性结论或独立测试集认证。

02 保留 Decimal 普通/加权求和；04 新增从数据集绑定实验组、指标后核对降幅或子项求和，可绑定已保存初稿版本，保存逐项来源。不是自动检出整篇数字，也不证明来源真实性。
